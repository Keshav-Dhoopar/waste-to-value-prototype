# Waste to Value

Waste to Value is a modern frontend web platform designed to bridge the gap between waste-generating factories and manufacturers who need affordable raw materials.

The platform works as a digital middleman, helping convert industrial waste into valuable resources, reducing pollution and production costs.

# Concept
"One person’s waste is another’s raw material."

# Features

-  Multi-role login (Admin, Waste Provider, Buyer) – simulated
-  Waste Provider Dashboard (add & manage waste listings)
-  Buyer Dashboard (browse & request materials)
-  Admin Panel (approve/reject listings)
-  Filters & search functionality
-  Order flow simulation (Request → Approved → Completed)
-  LocalStorage-based data (no backend required)
-  Fully responsive modern UI

# Tech Stack

- React + Vite
- HTML
- CSS
- JavaScript
- Context API (for state management)

# Note

This is a frontend prototype created for demonstration and academic purposes.  
Backend integration (Node.js / Firebase) can be added in future for real-world usage.
